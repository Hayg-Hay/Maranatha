# Hebrew Paleo Lachish

Unmodified `LACHISH.TTF` by Yoram Gnat (copyright 2007–2010), from the
Culmus Ancient Semitic Scripts 0.06-1 package. GPL version 2 with the
font embedding exception; see `HebrewPaleoLakhish-LICENSE.txt` and `GPL-2.txt`.
The matching upstream FontForge source is bundled in
`source/Hebrew-Paleo-Lachish.sfd`; the upstream source-package TTF is byte
identical to the binary distributed here (SHA-256
`311261e5321848316c42b21f5195d45558df470852a2bba23e78bc040856b877`).

- Project and corresponding source distribution:
  https://culmus.sourceforge.io/ancient/index.html
- Binary mirror (Git blob `997953f9a700194ae0b938de61fdcb683d50ff4c`):
  https://github.com/aharonium/fonts/tree/master/Fonts/Hebrew%20Letters%20only/Culmus%20Project%20(GPL%20and%20GPL%2BFE)/Yoram%20Gnat%20(GPL%2BFE)/Ancient-Semitic-Scripts-0.06-1/Hebrew%20Paleo%20Lakhish

The font supports the 22 letters at U+10900–U+10915. Unicode uses its
Phoenician block for Paleo-Hebrew as well; the font supplies Paleo-Hebrew
Lachish shapes. No font glyphs or encodings were modified.
