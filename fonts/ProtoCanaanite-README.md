The source's author note identifies online pictures, photographs and articles
as its references, with glyphs mainly comparable to Serabit el-Khadim
inscriptions. This is the author's modern interpretation, not a peer-reviewed
reconstruction of a complete alphabet or an ancient biblical manuscript.

The app labels this option "Proto-Sinaitic (approx.)". It retains the existing
WLC/OSHB consonantal text and uses the same 22 Phoenician character slots as
the Paleo display, rendered through this early-looking font. Copied text has
that existing encoding; it does not encode an independently reconstructed
Proto-Sinaitic text. All 22 slots have nonzero glyphs. No glyphs were modified.
