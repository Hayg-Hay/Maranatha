# Noto Sans Syriac v3.000 (Estrangela)

Official unmodified hinted regular TTF, extracted from:
https://github.com/notofonts/syriac/releases/tag/NotoSansSyriac-v3.000

Archive path: `NotoSansSyriac/hinted/ttf/NotoSansSyriac-Regular.ttf`.
The release identifies this family as the Estrangela style.
SIL OFL 1.1 is included in NotoSansSyriac-OFL.txt, copied from the same
official Noto Syriac project's licence already pinned for the Western family.
Archive and font hashes are recorded in build/sources/peshitta-font/font-manifest.json.

Used locally and precached for offline reading. Changing the display font
does not alter the underlying Syriac letters, punctuation, search or copied text.
