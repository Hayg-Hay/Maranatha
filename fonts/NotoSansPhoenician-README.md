The font covers the Unicode Phoenician block used by the app's visual
Paleo-Hebrew script conversion. It is a reading font, not a reconstruction
of any specific Hebrew manuscript. No glyphs or encodings were modified.

Siloam assets are retained temporarily for the user's font comparison.
