Subject: New Etchmiadzin 2017 - separate offline app and repository permissions

Dear Bible Society of Armenia,

I am developing Maranatha, an offline Bible reader, and would like to include
your New Etchmiadzin 2017 translation as a clearly identified Eastern Armenian
edition. Armenian Scripture is central to the project.

I am requesting as [individual or organization; full legal name]. The intended
distribution is free and non-commercial [confirm this description before
sending]. Project repository: https://github.com/Hayg-Hay/Maranatha.

Could you please consider these two requests separately?

A. Permission to bundle the complete translation in the application and its
downloadable offline distribution, including the publicly accessible GitHub
Pages website. Bundled JSON/JavaScript files contain the full Scripture text
and can be downloaded directly by anyone; excluding them from the public source
repository would not make the app distribution private. Readers could read,
search and copy passages offline. Technical conversion would preserve all
words/punctuation and keep headings/notes distinct. Please also cover creation
and distribution of derived search data/indexes, if used. Please specify limits
on public downloads, copying, technical conversion, attribution and updates.

B. Permission to publish the complete source text and converted data in a
public Git repository for reproducible builds and independent fidelity checks.
Those files would be directly downloadable and mirrorable. We would retain
your licence and notices, not automatically relicense the Scripture under
the application's code licence. If B is not permitted, could A still be
granted if original source/build data are kept outside the public source
repository, while the full-text app bundle remains publicly downloadable as
described in A? These permissions need separate answers.

If either use is possible, could you supply an authoritative structured
edition (USFM, USX or equivalent), complete book/appendix inventory, required
copyright notices, and licence or written grant? Please identify separate
terms for any annotations, and any conditions, fees or legal-entity requirements.
Please confirm the exact 2017 print edition/impression and whether the inventory
includes all its additions and appendices. If your organization does not handle
all relevant rights, who should receive these requests, and which rights do
you administer?
I would welcome a response clearly distinguishing permission for A and B.

Thank you for your help.
